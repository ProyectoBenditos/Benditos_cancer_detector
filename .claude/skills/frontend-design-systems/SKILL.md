# Frontend Design Systems Skill

## Overview
This skill guides the creation of coherent, scalable design systems and reusable frontend architectures using:
- React & TypeScript
- Tailwind CSS (v4 / v3 theme tokens)
- Modular component composition
- Spacing & alignment precision
- Predictable visual hierarchy

The goal is to ensure every interface looks like a cohesive product built by a design systems team, rather than fragmented, autogenerated pages.

---

## 1. Core Principles of Systemic Design

### 1. Spacing & Grid System
- Use an 8pt / 4pt grid system strictly.
- Margin and padding should derive from standard tokens:
  - Micro-spacing: `p-1`, `gap-1.5`, `p-2` (4px - 8px)
  - Component-spacing: `p-3`, `p-4`, `p-5`, `gap-3`, `gap-4` (12px - 20px)
  - Section-spacing: `p-6`, `p-8`, `py-12`, `py-16`, `py-24` (24px - 96px)
- Never use random arbitrary margins like `mt-[23px]` or `gap-[19px]`.

### 2. Type Scale & Hierarchical Weight
- **Display / H1:** `text-4xl md:text-5xl lg:text-6xl font-bold tracking-tight`
- **H2 / Section:** `text-2xl md:text-3xl font-bold tracking-tight text-slate-900`
- **H3 / Card Header:** `text-lg font-semibold text-slate-800`
- **Body:** `text-base text-slate-600 leading-relaxed`
- **Secondary / Meta:** `text-sm text-slate-500`
- **Caption / Tag:** `text-xs font-semibold uppercase tracking-wider`

### 3. Component Hierarchy
Design components in 3 distinct layers:
1. **Atoms (Primitives):** `Button`, `Input`, `Badge`, `Card`, `Tooltip`.
2. **Molecules (Patterns):** `SectionHeader`, `AlertBanner`, `MetricCard`, `BeforeAfterViewer`.
3. **Organisms (Sections):** `HeroSection`, `WorkflowSteps`, `MetricsStrip`, `ArchitectureBento`.

---

## 2. Preventing Visual Debt & "Template Drift"

1. **Token Adherence:** Never hardcode hex codes in component files. Always use theme variables (`text-brand-primary`, `bg-brand-danger`, `border-slate-200`).
2. **State Uniformity:** Every interactive element must define standard states:
   - Default
   - Hover (`hover:`)
   - Focus visible (`focus-visible:ring-2 focus-visible:ring-brand-primary`)
   - Active (`active:scale-[0.98]`)
   - Disabled (`disabled:opacity-50 disabled:pointer-events-none`)
3. **Surface Elevation:** Choose between flat borders (`border border-slate-200`) or subtle soft elevation. Do not mix heavy dark shadows with flat borderless cards on the same page.
